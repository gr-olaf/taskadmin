# Техническое задание: TaskAdmin — Управление задачами (frontend-only)

## 1. Общее описание

**Название системы:** TaskAdmin

**Назначение:** Клиентское (frontend) веб-приложение для создания, хранения и просмотра задач, позволяющее пользователям систематизировать и организовывать рабочий процесс.

**Технологический стек:** HTML, CSS и JavaScript (без бэкенд-серверов) + фреймворк **Bootstrap 5** (через CDN) для вёрстки и UI-компонентов.

**Запуск:** Открытие локального `index.html` в браузере (SPA, одностраничное приложение).

**Целевой пользователь:** Любой пользователь, нуждающийся в простом инструменте для управления списком задач в браузере.

## 3. Модель данных (в памяти + localStorage)

### Сущность: Task (Задача)

| Поле | Тип данных | Ограничения | Описание |
|------|-----------|-------------|----------|
| `id` | String | Уникальный, генерируется при создании (напр. `Date.now()` + случайное число) | Идентификатор задачи |
| `title` | String | Обязательное, 1–255 символов | Заголовок задачи |
| `description` | String | Необязательное, до 2000 символов | Описание задачи |
| `created_at` | String (ISO-дата) | Автоматически при создании | Дата и время создания |

**Хранение:** Массив задач в памяти JS + сериализация в `localStorage` (ключ, напр. `taskadmin_tasks`).

## 4. Детали интерфейса и реализация

### 4.1. Структура файлов

```
/
├── index.html          # Разметка страницы и формы (на Bootstrap)
├── css/style.css       # Дополнительные стили поверх Bootstrap (адаптивные)
└── js/app.js           # Вся логика приложения (рендер, валидация, хранение)
```

### 4.2. Подключение Bootstrap

- Bootstrap 5 подключается через CDN в `index.html`:
  - CSS: `<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">`
  - JS (Bundle): `<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">`
- Используются стандартные Bootstrap-компоненты:
  - Кнопки (`btn`, `btn-primary`, `btn-danger`, `btn-outline-secondary`)
  - Формы (`form-group` / `mb-3`, `form-control`, `form-label`, `invalid-feedback`)
  - Карточки (`card`, `card-body`)
  - Сетка и утилиты (`container`, `row`, `col`, `d-flex`, `gap`, `text-muted`)

### 4.3. Разметка (index.html)

- Заголовок страницы: **«Управление задачами»**
- Кнопка «Создать задачу» — `btn btn-primary`
- Список задач — контейнер из карточек `card` / `card-body`
- Каждая карточка задачи содержит:
  - Заголовок (`card-title`)
  - Описание (`card-text`)
  - Дату создания (`text-muted`)
  - Кнопки «Редактировать» (`btn btn-sm btn-outline-secondary`) и «Удалить» (`btn btn-sm btn-outline-danger`)
- Форма создания (скрытая по умолчанию, показ/скрытие через класс):
  - Поле «Заголовок задачи» — `<input class="form-control">`
  - Поле «Описание задачи» — `<textarea class="form-control">`
  - Кнопка «Сохранить» — `btn btn-primary` (`type="submit"`)
  - Кнопка «Отмена» — `btn btn-secondary` (`type="button"`)
  - Блоки ошибок валидации — `invalid-feedback`

### 4.4. Стилизация (css/style.css)

- Стили `style.css` лишь дополняют Bootstrap (цвета, отступы, состояния)
- Адаптивность реализуется средствами Bootstrap-сетки (`container`, `col`-классы)
- Язык текстов в интерфейсе — русский

### 4.5. Логика (js/app.js)

Основные функции:

- `loadTasks()` — чтение задач из `localStorage` (или пустой массив)
- `saveTasks()` — запись массива задач в `localStorage`
- `renderTasks()` — отрисовка списка
- `showForm() / hideForm()` — управление формой
- `handleSubmit(event)` — валидация и добавление задачи
- `createTask(title, description)` — создание объекта задачи
- `deleteTask(id)` — удаление задачи по `id` из массива и localStorage
- `editTask(id)` — открытие формы с заполненными данными задачи для редактирования
- `updateTask(id, title, description)` — обновление задачи по `id`
- `reorderTasks(fromIndex, toIndex)` — изменение порядка задач при DnD
- Инициализация: подписка на события `submit`, `click`, `dragstart`, `dragover`, `drop`, загрузка и первичный рендер при `DOMContentLoaded`

**Реализация Drag and Drop (FR-25–FR-29):**
- Используются нативные HTML5 события DnD (`dragstart`, `dragover`, `dragenter`, `dragleave`, `drop`, `dragend`)
- Элементу карточки присваивается `draggable="true"`
- При наведении на позицию вставки добавляется CSS-класс (например `.drag-over`) с визуальным индикатором
- По событию `drop` вычисляется целевой индекс и вызывается `reorderTasks()`, после чего список перерисовывается и сохраняется в localStorage

**Обработка валидации (FR-06):**
- Пустой заголовок → показать сообщение «Заголовок обязателен»
- Заголовок длиннее 255 символов → показать сообщение «Заголовок слишком длинный»
- Описание длиннее 2000 символов → показать сообщение
