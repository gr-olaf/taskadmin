# Техническое задание: TaskAdmin — Управление задачами (frontend-only)

## 1. Общее описание

**Название системы:** TaskAdmin

**Назначение:** Клиентское (frontend) веб-приложение для создания, хранения и просмотра задач, позволяющее пользователям систематизировать и организовывать рабочий процесс.

**Технологический стек:** Чистые HTML, CSS и JavaScript (без фреймворков и бэкенд-серверов).

**Запуск:** Открытие локального `index.html` в браузере (SPA, одностраничное приложение).

**Целевой пользователь:** Любой пользователь, нуждающийся в простом инструменте для управления списком задач в браузере.

## 3. Модель данных (в памяти + localStorage)

### Сущность: Task (Задача)

| Поле | Тип данных | Ограничения | Описание |
|------|-----------|-------------|----------|
| `id` | String | Уникальный, генерируется при создании (напр. `Date.now()` + случайное число) | Идентификатор задачи |
| `title` | String | Обязательное, 1–255 символов | Заголовок задачи |
| `description` | String | Необязательное, до 2000 символов | Описание задачи |
| `created_at` | String (ISO-дата) | Автоматически при создании | Дата и время создания |

**Хранение:** Массив задач в памяти JS + сериализация в `localStorage` (ключ, напр. `taskadmin_tasks`).

## 4. Детали интерфейса и реализация

### 4.1. Структура файлов

```
/
├── index.html          # Разметка страницы и формы
├── css/style.css       # Стили (адаптивные)
└── js/app.js           # Вся логика приложения (рендер, валидация, хранение)
```

### 4.2. Разметка (index.html)

- Заголовок страницы: **«Управление задачами»**
- Кнопка «Создать задачу»
- Список задач `<ul>` / `<div>` — контейнер для карточек задач
- Каждая карточка задачи содержит кнопку удаления (иконка или текст «Удалить»)
- Каждая карточка задачи содержит кнопку редактирования (иконка или текст «Редактировать»)
- Форма создания (скрытая по умолчанию, с классом для показа/скрытия):
  - Поле «Заголовок задачи» — `<input type="text">`
  - Поле «Описание задачи» — `<textarea>`
  - Кнопка «Сохранить» — `<button type="submit">`
  - Кнопка «Отмена» — `<button type="button">`
  - Блок ошибки валидации — `<span class="error">`

### 4.3. Стилизация (css/style.css)

- Современный, минималистичный дизайн (карточки, тени, скругления)
- Адаптивная вёрстка (grid/flex): десктоп — несколько колонок, мобильный — одна колонка
- Стилизация состояний: hover, focus, disabled
- Язык текстов в интерфейсе — русский

### 4.4. Логика (js/app.js)

Основные функции:

- `loadTasks()` — чтение задач из `localStorage` (или пустой массив)
- `saveTasks()` — запись массива задач в `localStorage`
- `renderTasks()` — отрисовка списка
- `showForm() / hideForm()` — управление формой
- `handleSubmit(event)` — валидация и добавление задачи
- `createTask(title, description)` — создание объекта задачи
- `deleteTask(id)` — удаление задачи по `id` из массива и localStorage
- `editTask(id)` — открытие формы с заполненными данными задачи для редактирования
- `updateTask(id, title, description)` — обновление задачи по `id`
- Инициализация: подписка на события `submit`, `click`, загрузка и первичный рендер при `DOMContentLoaded`

**Обработка валидации (FR-06):**
- Пустой заголовок → показать сообщение «Заголовок обязателен»
- Заголовок длиннее 255 символов → показать сообщение «Заголовок слишком длинный»
- Описание длиннее 2000 символов → показать сообщение
